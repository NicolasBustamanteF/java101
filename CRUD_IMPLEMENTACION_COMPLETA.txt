🔧 OPERACIONES CRUD IMPLEMENTADAS
═════════════════════════════════════════════════════════════════════════════════

✨ OPERACIONES BÁSICAS (5 principales solicitadas)

1️⃣ ADD (CREATE / INSERT)
   ├─ Método: public int add(String descripcion)
   ├─ SQL: INSERT INTO categoria (descripcion) VALUES (?)
   ├─ Retorna: ID de la categoría creada
   └─ Ejemplo: int id = dao.add("Electrónica");

2️⃣ DELETE (ELIMINAR)
   ├─ Método: public boolean delete(int idCategoria)
   ├─ SQL: DELETE FROM categoria WHERE id_categoria = ?
   ├─ Retorna: true si se eliminó, false si no encontró
   └─ Ejemplo: dao.delete(1);

3️⃣ UPDATE (ACTUALIZAR)
   ├─ Método: public boolean update(int idCategoria, String descripcion)
   ├─ SQL: UPDATE categoria SET descripcion = ? WHERE id_categoria = ?
   ├─ Retorna: true si se actualizó, false si no encontró
   └─ Ejemplo: dao.update(1, "Nueva descripción");

4️⃣ SELECT (CONSULTAR TODOS)
   ├─ Método: public List<Categoria> select()
   ├─ SQL: SELECT id_categoria, descripcion FROM categoria ORDER BY id_categoria
   ├─ Retorna: Lista de todas las categorías
   └─ Ejemplo: List<Categoria> categorias = dao.select();

5️⃣ SELECT BY ID (CONSULTAR POR ID)
   ├─ Método: public Categoria selectById(int idCategoria)
   ├─ SQL: SELECT id_categoria, descripcion FROM categoria WHERE id_categoria = ?
   ├─ Retorna: Categoría encontrada o null
   └─ Ejemplo: Categoria cat = dao.selectById(1);

✨ OPERACIONES ADICIONALES

6️⃣ SELECT BY DESCRIPCION (BÚSQUEDA CON LIKE)
   ├─ Método: public List<Categoria> selectByDescripcion(String descripcion)
   ├─ SQL: SELECT ... FROM categoria WHERE descripcion ILIKE ? ORDER BY id_categoria
   ├─ Retorna: Lista de categorías que contienen el texto
   ├─ Características:
   │  └─ Búsqueda parcial (no requiere coincidir exactamente)
   │  └─ Insensible a mayúsculas/minúsculas (ILIKE)
   │  └─ Usa % para envolver el término de búsqueda
   └─ Ejemplo:
      dao.selectByDescripcion("Electró")    // Encuentra "Electrónica"
      dao.selectByDescripcion("y")          // Encuentra todo con "y"

7️⃣ GET TOTAL CATEGORIAS
   ├─ Método: public int getTotalCategorias()
   ├─ SQL: SELECT COUNT(*) as total FROM categoria
   └─ Retorna: Número total de categorías

8️⃣ DELETE ALL (para pruebas)
   ├─ Método: public void deleteAll()
   ├─ SQL: DELETE FROM categoria
   └─ Uso: Limpiar datos para pruebas

9️⃣ CREATE TABLE
   ├─ Método: public void createTable()
   ├─ SQL: CREATE TABLE IF NOT EXISTS categoria (...)
   └─ Crea la tabla automáticamente en la primera ejecución

💻 USO EN TU CÓDIGO
═════════════════════════════════════════════════════════════════════════════════

EJEMPLO SIMPLE:

import py.com.nikosoft.depositos.boundary.CategoriaDAO;
import py.com.nikosoft.depositos.entities.Categoria;
import java.sql.SQLException;
import java.util.List;

public class MiApp {
    public static void main(String[] args) {
        try {
            CategoriaDAO dao = new CategoriaDAO();

            // Crear tabla
            dao.createTable();

            // Insertar
            int id = dao.add("Electrónica");
            System.out.println("Creada con ID: " + id);

            // Consultar todas
            List<Categoria> todas = dao.select();
            for (Categoria cat : todas) {
                System.out.println(cat.getId() + ": " + cat.getDescripcion());
            }

            // Consultar por ID
            Categoria cat = dao.selectById(id);
            System.out.println("Encontrada: " + cat.getDescripcion());

            // Buscar por descripción
            List<Categoria> resultados = dao.selectByDescripcion("Electró");
            System.out.println("Encontradas: " + resultados.size());

            // Actualizar
            dao.update(id, "Electrónica y Gadgets");

            // Eliminar
            dao.delete(id);

        } catch (SQLException e) {
            e.printStackTrace();
        }
    }
}
