3. Abre PowerShell y navega al proyecto:
   cd "C:\Users\nicob\OneDrive\Documentos\repositorio\java101"

4. Compila:
   mvn clean compile

5. Ejecuta el ejemplo:

📞 AYUDA SI ALGO FALLA
════════════════════════

Error: "Maven no está instalado"
  → Lee: MANUAL_MAVEN_INSTALL.md
  → O ejecuta: Install-Maven.ps1

Error: "PostgreSQL no se conecta"
  → Verifica que PostgreSQL está corriendo
  → Windows: Services → Buscar "PostgreSQL" → Iniciar

Error: "Connection refused"
  → Verificar que PostgreSQL escucha en localhost:5432
  → Comando: psql -h localhost

Error: "Usuario o contraseña inválida"
  → Verifica que creaste el usuario 'develop'
  → Con contraseña exacta: develop123

Error: "Cannot find symbol"
  → Ejecuta: mvn clean compile
  → Espera a que descargue las dependencias

Más detalles en: INDICE.md
