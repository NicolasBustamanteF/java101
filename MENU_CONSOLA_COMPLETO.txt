🎯 OPERACIONES IMPLEMENTADAS
═════════════════════════════════════════════════════════════════════════════════

1️⃣ AGREGAR NUEVA CATEGORÍA
   ├─ Solicita descripción
   ├─ Valida que no esté vacía
   ├─ Inserta en BD
   └─ Muestra ID asignado

2️⃣ VER TODAS LAS CATEGORÍAS
   ├─ Consulta todas las categorías
   ├─ Muestra en tabla formateada
   ├─ Trunca descripciones largas
   └─ Muestra total

3️⃣ BUSCAR CATEGORÍA POR ID
   ├─ Solicita ID numérico
   ├─ Valida que sea número
   ├─ Busca en BD
   └─ Muestra resultado o error

4️⃣ BUSCAR POR DESCRIPCIÓN (LIKE)
   ├─ Búsqueda parcial flexible
   ├─ Insensible a mayúsculas
   ├─ Muestra múltiples resultados
   └─ Muestra cantidad encontrada

5️⃣ ACTUALIZAR CATEGORÍA
   ├─ Solicita ID
   ├─ Verifica que exista
   ├─ Muestra descripción actual
   ├─ Solicita nueva descripción
   └─ Actualiza en BD

6️⃣ ELIMINAR CATEGORÍA
   ├─ Solicita ID
   ├─ Verifica que exista
   ├─ Muestra información
   ├─ PIDE CONFIRMACIÓN (s/n)
   └─ Elimina si confirma

7️⃣ VER TOTAL DE CATEGORÍAS
   ├─ Cuenta registros
   └─ Muestra total

0️⃣ SALIR
   └─ Cierra la aplicación
