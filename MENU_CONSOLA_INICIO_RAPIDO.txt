   cd C:\Users\nicob\OneDrive\Documentos\repositorio\java101

PASO 2: Compila el proyecto
   mvn clean compile

   mvn exec:java -Dexec.mainClass="py.com.nikosoft.depositos.controller.CategoriaMenu"

¡Listo! El menú aparecerá en la consola.

═════════════════════════════════════════════════════════════════════════════════
🎯 OPERACIONES
═════════════════════════════════════════════════════════════════════════════════

1️⃣ AGREGAR NUEVA CATEGORÍA
   └─ Ingresa una descripción
   └─ Se asigna automáticamente un ID
   └─ Ejemplo: "Electrónica", "Ropa", "Hogar", etc.

2️⃣ VER TODAS LAS CATEGORÍAS
   └─ Muestra un listado en tabla de todas las categorías
   └─ Muestra ID y descripción
   └─ Muestra el total

3️⃣ BUSCAR POR ID
   └─ Busca una categoría específica
   └─ Debes conocer el ID
   └─ Muestra la información si existe

4️⃣ BUSCAR POR DESCRIPCIÓN (BÚSQUEDA PARCIAL/LIKE)
   └─ Búsqueda flexible
   └─ No necesita la descripción completa
   └─ Ejemplo: Si buscas "Electró" encuentra "Electrónica"
   └─ Ejemplo: Si buscas "y" encuentra "Ropa y Accesorios", "Hogar y Decoración"

5️⃣ ACTUALIZAR CATEGORÍA
   └─ Ingresa el ID de la categoría a actualizar
   └─ Ingresa la nueva descripción
   └─ Se actualiza en la base de datos

6️⃣ ELIMINAR CATEGORÍA
   └─ Ingresa el ID a eliminar
   └─ Pide confirmación (s/n)
   └─ Se elimina si confirmas

7️⃣ VER TOTAL DE CATEGORÍAS
   └─ Muestra cuántas categorías hay registradas

0️⃣ SALIR
   └─ Cierra la aplicación

✨ CARACTERÍSTICAS DEL MENÚ
═════════════════════════════════════════════════════════════════════════════════

✅ Interfaz visual clara
   └─ Menú formateado con bordes y emojis
   └─ Navegación intuitiva

✅ Validación de entrada
   └─ Verifica IDs numéricos
   └─ No permite descripciones vacías
   └─ Rechaza opciones inválidas

   └─ Pide confirmación antes de eliminar
   └─ Evita borrados accidentales

   └─ Búsqueda parcial de descripción
   └─ Insensible a mayúsculas/minúsculas
   └─ Muestra todos los resultados en tabla

✅ Tabla formateada
   └─ Resultados en formato tabla
   └─ Fácil de leer
   └─ Ancho adaptado

✅ Mensajes informativos
   └─ ✓ para operaciones exitosas
   └─ ✗ para errores
   └─ ℹ para información

🆘 SOLUCIÓN DE PROBLEMAS
═════════════════════════════════════════════════════════════════════════════════

"ERROR: Could not connect to PostgreSQL"
└─ PostgreSQL no está ejecutándose
└─ Solución: Iniciar el servicio de PostgreSQL

"Error: La descripción no puede estar vacía"
└─ Se intentó ingresar una descripción vacía
└─ Solución: Ingresar una descripción válida

"ID inválido. Debe ser un número"
└─ Se ingresó un valor no numérico para ID
└─ Solución: Ingresar solo números

"Categoría no encontrada"
└─ El ID ingresado no existe
└─ Solución: Usar opción 2 para ver IDs válidos
